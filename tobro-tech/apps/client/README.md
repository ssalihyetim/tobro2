# Tobro Tech Frontend

This is the React frontend for Tobro Tech's CNC Machining & Manufacturing website.

## Features
- Modern, responsive homepage with hero section and services cards
- Service cards show name, description, and benefits (no images)
- Built with React 18, React Router 6, and Vite

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Project Structure
- `src/pages/Home.jsx`: Homepage with hero and services
- `src/styles/Home.module.css`: Homepage styles
- `src/App.jsx`: Main app routes
- `src/main.jsx`: App entry point

## Notes
- Service images are not included; add them later as needed.
- Placeholder routes for service detail pages.
